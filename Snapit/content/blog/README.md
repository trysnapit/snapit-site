# Add a blog post

Send a title and the article. Save a new `.md` file in this folder with `title`, `date`, and `summary` in the front matter. The filename, without `.md`, is the URL. Do not edit the home page or the layout.

Example:

```md
---
title: The post title
date: "2026-10-13"
summary: One or two sentences.
---

The article starts here.
```
