Snapit posts the bill into Xero, QuickBooks, or Zoho Books. If you use another system, the same invoice can land there through the REST API or a webhook. The WhatsApp step stays the same for staff.

Live now:

- Xero
- QuickBooks
- Zoho Books

Coming soon:

- NetSuite
- Odoo
- ERPNext
- SQL Account
- Mekari Jurnal
- Accurate

The REST API pulls invoice data and documents. Webhooks push each invoice when it is read. Your team still only snaps and sends.
